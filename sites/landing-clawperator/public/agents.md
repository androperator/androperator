# Clawperator For Agents

Clawperator is a deterministic Android automation actuator for AI agents. The
external agent remains the brain that plans and asks for approval; Clawperator
is the hand that executes validated Android actions and returns structured
results.

Tell your agent:

```text
Read https://clawperator.com/skill.md and get me set up with Clawperator.
```

Shell fallback:

```bash
curl -fsSL https://clawperator.com/install.sh | bash
```
