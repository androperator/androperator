For agents

Start with the setup skill and agent guidance. Use the documentation index or full technical documentation for action contracts. The homepage README is also available as Markdown.

You choose the actions and judge the outcome. Androperator executes your commands, reports results, and exposes the Android UI through snapshots and screenshots. Use that feedback to choose your next step. Select a device, verify readiness with androperator doctor, observe its UI, execute explicit actions, and verify the returned state. Keep commandId and taskId when correlating results. Treat host errors and timeouts as failures to investigate, not evidence of success.

Androperator - Android visibility and control. Your agent decides. Androperator executes and reports.
